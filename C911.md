## File-naming convention

Pattern: `<content>-g09-<book>-<node>.<ext>`

- `tadris` = teaching; `tamrin` = textbook exercises.
- `az-nokat` = literary/language notes; `grammar` = grammar notes; `e-nokat` = exam notes.
- `n-soal` = sample questions; `flash` = flash cards; `selftest` = self-test.
- `guide` = guide; `rowkhan` / `khanesh` = reading; `noorani` = Quranic section.
- HTML uses `.html`; audio uses `.mp3`; existing PDF names are not renamed.

⚠️ در `books-menu.json` فعلی، آیتم‌های اجرایی C911 خالی است؛ بنابراین هیچ تب جدیدی به این فایل اضافه نشده است. عنوان‌ها فقط از درخت رسمی `BookToc.kt` نگه داشته شده‌اند.
