# پرامپت: ماژول آزمون بازه‌ای، اصلاح خودکار، بازخورد، و برنامه‌ریزی هفتگی بر اساس برنامه‌ی کلاسی/شیفت چرخشی

## بخش ۱ — آزمون‌گیری بر اساس بازه‌ی درسی
هر کتاب به بازه‌های درسی (مثلاً فصل‌ها یا هر ۳-۴ درس) تقسیم شود و در پایان هر بازه یک آزمون کوتاه تولید شود.

### مدل داده
```json
{
  "examId": "string",
  "bookCode": "string",
  "rangeGroup": "string",        // همان examRangeGroup در فایل ۰۵
  "questions": [{ "questionId": "string", "type": "mcq|short_answer", "weight": "number" }],
  "assignedAt": "ISO8601",
  "dueAt": "ISO8601|null"
}
```
```json
// نتیجه‌ی آزمون هر کاربر
{
  "examId": "string",
  "userId": "string",
  "answers": [{ "questionId": "string", "givenAnswer": "string", "isCorrect": "boolean" }],
  "score": "number",
  "weakTopics": ["string"],     // موضوعاتی که غلط پاسخ داده شده
  "takenAt": "ISO8601"
}
```

## بخش ۲ — اصلاح خودکار و بازخورد
- سوالات چندگزینه‌ای: اصلاح فوری و محلی.
- سوالات تشریحی کوتاه: با همان Appwrite Function AI (از فایل ۰۴، از provider فعال) ارزیابی و نمره‌دهی تقریبی + بازخورد متنی کوتاه شود.
- بعد از هر آزمون: صفحه‌ی «نکات ضعف» نمایش داده شود که فقط `weakTopics` را با لینک مستقیم به همان نکته‌ی کلیدی/فلش‌کارت مرتبط نشان دهد (نه کل درس دوباره).

## بخش ۳ — برنامه‌ریزی هفتگی بر اساس برنامه‌ی کلاسی و شیفت چرخشی
اپ باید بتواند برنامه‌ی هفتگی مرور را بر اساس: (الف) برنامه‌ی کلاسی هفتگی زهرا (کدام درس کدام روز کلاس دارد)، (ب) شیفت چرخشی (اگر برنامه‌ی هفتگی هر هفته یا هر چند هفته جابه‌جا می‌شود)، خودکار بچیند.

### مدل داده (`weekly_schedule`)
```json
{
  "cycleWeekIndex": "number",     // برای شیفت چرخشی: کدام هفته از چرخه
  "dayOfWeek": "string",
  "classSlots": [{ "bookCode": "string", "startTime": "string", "endTime": "string" }]
}
```
```json
// برنامه‌ی مرور تولیدشده
{
  "userId": "string",
  "date": "ISO8601",
  "reviewTasks": [
    { "bookCode": "string", "type": "flashcard|video|exam|prerequisite", "refId": "string", "isDone": "boolean" }
  ]
}
```

### منطق تولید برنامه‌ی مرور (پرامپت برای Appwrite Function `weekly-plan-engine`)
> «با توجه به `weekly_schedule` (شامل `cycleWeekIndex` برای شیفت چرخشی) و تاریخ امروز:
> ۱. مشخص کن امروز کدام هفته از چرخه است و امروز چه دروسی کلاس دارند.
> ۲. برای هر درسی که «فردا» کلاس دارد، یک تسک مرور فلش‌کارت + نکات کلیدی همان درس برای «امشب» بساز.
> ۳. برای دروسی که در ۷ روز اخیر آزمون بازه‌ای داشته‌اند و `weakTopics` دارند، یک تسک مرور نقطه‌ضعف اضافه کن.
> ۴. اگر امروز روز آزادی از کلاس‌هاست، یک تسک «مرور آزاد» برای پرتکرارترین دروسِ ضعیف بگذار.
> خروجی JSON را در `weekly_schedule/review_tasks` بنویس و به کاربر (و در صورت فعال بودن، والدین از طریق `notify-guardian`) اعلان بفرست.»

## معیار پذیرش
- [ ] در پایان هر بازه‌ی درسی، آزمون به‌صورت خودکار در دسترس کاربر قرار می‌گیرد.
- [ ] بعد از آزمون، صفحه‌ی نکات ضعف با لینک مستقیم به منبع مرتبط نمایش داده می‌شود.
- [ ] برنامه‌ی مرور هفتگی با توجه به برنامه‌ی کلاسی و شیفت چرخشی، هر روز به‌روزرسانی می‌شود.
