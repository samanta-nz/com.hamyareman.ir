نقشهٔ آپلود فایل‌های HTML همیار من

فهرست مسیرهای فعلی مخزن برای باکت پارس‌پک، به همراه مراجع قدیمیِ جداشده از فهرست فعال.

میزبان عمومی: https://c539776.parspack.net · باکت: c539776

روش آپلود هر فایل فعال
  1. در پنل پارس‌پک، باکت c539776 را باز کنید.
  2. فایل HTML را با همان مسیرِ ستون «Object Key دقیق» و با حفظ تمام پیشوندها/زیرپوشه‌ها بارگذاری کنید. مثلاً کلید Bucket/Html-files/آموزشگاه/04-note-taking.html باید دقیقاً با همین نام کلید در باکت ثبت شود.
  3. در این ساختار، Bucket/ بخشی از نام کلید است؛ آن را حذف نکنید و c539776/ را نیز به ابتدای کلید اضافه نکنید.
  4. فایل‌های HTML مورد انتظار این برنامه باید با قالب رمز‌شدهٔ HMK1 بارگذاری شوند، نه متن HTML خام. برای تولید نسخهٔ رمز‌شده، از همان اسکریپت/فرایند بسته‌بندی پروژه استفاده کنید.
HTMLهای زیر مسیر Bucket/Pdf-files/... نیز در کد منوی کتاب‌ها به‌عنوان صفحهٔ HTML تدریس ارجاع داده شده‌اند. اسم پوشه را اصلاح یا منتقل نکنید؛ فایل را دقیقاً زیر همان Object Key ثبت‌شده آپلود کنید.

فایل‌های واقعاً پویا که مقدارشان در Appwrite ثبت می‌شود

فهرست زیر همهٔ کلیدهای موجود در فایل‌های فعلی مخزن و CSV مستندات را جمع می‌کند؛ اما کتاب‌هایی که مدیر بعداً از پنل اضافه می‌کند قابل پیش‌بینی و فهرست‌کردن در APK نیستند. برای آن‌ها، مقدار htmlKey در رکورد کتاب و مقدار mediaKey در فصل را بررسی کنید: اگر با Bucket/ شروع می‌شود، همان مقدار Object Key مقصد است؛ اگر شناسه‌ای مانند tool-calendar.html است، باید برای آن شناسه در server-map.json یک نگاشت id → key وجود داشته باشد و فایل در مسیرِ key آپلود شود.
